# AssistedCareHub Resources (blog content)

Approved articles for www.assistedcarehub.com/blog. The website reads this repo on every build.

- `posts/<slug>.md` — one article each (front matter: title, description, date, image, imageAlt, facebook; optional `draft: true`).
- `images/<slug>.jpg` — 1200x630 share image for each article.

A post appears on the site on the first daily rebuild on or after its `date`. Only approved posts are committed here; drafts stay private on Robbie's server.
